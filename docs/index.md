# Scribe IQ

Scribe IQ is a governed clinical documentation AI prototype built on synthetic data. It demonstrates how institutional data platform architecture patterns translate into healthcare-shaped AI workflows: longitudinal records, grounded RAG, chart review, note generation, provider boundaries, and Responsible AI auditability.

Built on synthetic data only. Not for clinical decision-making.
