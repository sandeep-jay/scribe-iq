## Local security checks

Set up local pre-commit hooks (including gitleaks) once per clone:

```bash
pip install pre-commit
pre-commit install
```

Run secret checks on demand:

```bash
pre-commit run gitleaks --all-files
```

### Cursor attribution guards

This repo ships three versioned git hooks under [`../../.githooks/`](../../.githooks/) that strip or block Cursor-related attribution from commit messages and PRs:

- `commit-msg` and `prepare-commit-msg` — strip `Co-authored-by: Cursor <cursoragent@cursor.com>` trailers, `Made with [Cursor](...)` lines, `Generated by Cursor`, `Via Cursor`, and similar variants from the in-progress commit message.
- `pre-push` — refuses to push commits whose messages still contain Cursor attribution after the strip pass; edit those commits with `git rebase -i` and retry.

Wire them up (once per clone):

```bash
./scripts/install_dev_hooks.sh
```

That sets `git config core.hooksPath .githooks` and makes the hook files executable. Do not bypass with `--no-verify`.

Authoring guidance: never write "Made with Cursor", links to `cursor.com`, or `Co-authored-by: Cursor ...` in commit messages, PR titles/bodies, or review/issue comments. The Cursor rule at [`../../.cursor/rules/no-cursor-attribution.mdc`](../../.cursor/rules/no-cursor-attribution.mdc) captures the same guidance for AI agents that author commits through Cursor.
