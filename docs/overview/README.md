# Overview

The overview layer is the **portfolio narrative** layer of this repository. It is written for product, design, and engineering reviewers who want to understand what was built, why it was built that way, and where the production deltas are — without reading the implementation.

| Doc | Audience | What you will learn |
|-----|----------|---------------------|
| [PORTFOLIO_CASE_STUDY.md](PORTFOLIO_CASE_STUDY.md) | Recruiters, hiring managers, portfolio reviewers | One-page story of the project: why it exists, what it demonstrates, what is intentionally not production-ready |
| [PRODUCT_CONTEXT.md](PRODUCT_CONTEXT.md) | Product managers, directors, design leads | Problem statement, scope boundary, deferred decisions and why |
| [SYSTEM_OVERVIEW.md](SYSTEM_OVERVIEW.md) | Architects, staff engineers | Runtime diagrams, capability flags, extension seams, provider boundary |
| [DESIGN_NOTES.md](DESIGN_NOTES.md) | Senior engineers, reviewers | Decisions, alternatives considered, what would change for production |
| [PRIVACY_AND_PROVIDER_BOUNDARIES.md](PRIVACY_AND_PROVIDER_BOUNDARIES.md) | Security and compliance readers | PHI posture, provider egress, audit redaction, enterprise caveats |
| [RESUME_SNIPPETS.md](RESUME_SNIPPETS.md) | The author (and recruiters who land here) | Drop-in resume, healthcare-targeted, and LinkedIn-length descriptions |
